# 上咨设计平台接入

1. 把 wall-designer 目录中的前端文件及 vendor 复制到平台根目录的 02 制图工具/10 画护岸/。测试、本文档和补丁不是运行依赖。
2. 在平台根目录先运行 git apply --ignore-space-change --check <本目录>/platform.patch，再使用相同选项应用补丁。此选项兼容平台文件原有的 LF/CRLF 差异。若本地已经接入，无需再次应用；其他版本的上下文不同则按补丁逐项迁移。
3. 把本目录的 wall.svg 复制为 00 主站服务/icon/wall.svg。
4. 运行平台现有的「同步样式.py」，按原流程分发公共母版。
5. 单独重启 00 主站服务/server.py，现有反向代理继续工作；无需增加子服务端口。

补丁只包含本功能的入口变更，依赖既有上咨设计平台代码，不能在此独立 demo 仓库直接应用。新入口位于画桥后；/wall/* 由主站静态映射到新目录。根目录的 app-shell.js/css 为公共母版，按平台既有机制同步副本。_nav_pages.tsv 只是导航清单，运行时入口来自 app-shell.js。

补丁不含平台环境变量、密钥、DWG 原图、运行数据或其他业务功能源码。
