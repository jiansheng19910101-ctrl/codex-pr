# 河道挡墙参数化设计

无需安装、无需联网的单文件 HTML 工具。下载 `index.html`，用 Chrome 或 Edge 打开。

## 功能

- 钢筋混凝土悬臂式挡墙、浆砌块石重力式挡墙。
- 简版 8 项参数与详版尺寸输入。
- 实时断面预览；拖动墙顶或墙高尺寸线调整高度，拖动基础端点调整宽度。
- 鼠标与触屏操作；方向键微调，Shift 精调。
- DXF 导出，模型空间单位为米。
- 详版尺寸参数 JSON 保存与导入。

## 参数约定

墙高为基础顶至墙顶的高度。坡比为竖向∶水平＝1∶m。简版采用页面说明中的默认尺寸；详版可分别控制。其他可选构造尺寸目前仅随参数文件保存，不绘入断面。

本工具用于断面几何设计，不包含稳定验算和结构设计。已验证几何及尺寸联动逻辑，实际浏览器拖动与 CAD 兼容性仍需现场验证。

## 文件

`index.html` 为主入口，可用于 GitHub Pages；`挡墙参数化设计.html` 为同内容的中文命名离线版本。
