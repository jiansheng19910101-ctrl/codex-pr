画护岸 · 参数化断面 Demo

选择钢筋混凝土悬臂式或浆砌石重力式护岸。左侧修改参数，右侧同步更新三维模型；展开「二维断面与尺寸」可拖动蓝色节点调整墙高与基础宽。

图纸与参数

「断面图一键绘制」生成米制 DXF，墙体、基础、地形、尺寸和文字分层。可另存 SVG 断面图、PNG 三维图，以及 JSON 参数。原 GitHub 尺寸参数文件可导入；未绘制的可选构造尺寸仅原样保留。

三维与土体

墙体和基础均按当前断面沿护岸纵向拉伸 15 m。土体边界按墙前地形、墙后地形和基底下方 1.5 m 封闭，属于展示范围，不是实测地质。示意水面取河底与墙前平台之间的高度，不是设计或实测水位。

拖动旋转，滚轮缩放，右键拖动平移。可切换三维、俯视、侧视和断面，或点击复位。参数调整保留视角，平台内切换工作区保留当前会话。

参数口径

墙高为基础顶至墙顶的高度。坡比为竖向∶水平＝1∶m。简版沿用上游的 8 项输入和默认尺寸，详版单独调整地形、墙体与基础。土体长度和三维示意段长固定为 15 m。

来源与使用范围

核心几何、默认参数、二维拖动和 DXF 生成来自 GitHub 上游代码。界面与三维操作参照本平台画桥单跨版；专业构造关系参考现有护岸典型断面图。未将参考图纸尺寸当作默认参数依据。

本 demo 用于几何展示与出图试用，不包含稳定验算、配筋、工程量审核及完整施工构造。DXF 的实际 CAD 字体和导入效果需结合目标 CAD 检查。
