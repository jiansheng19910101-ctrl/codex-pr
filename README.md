# codex-pr

Repository for code developed with Codex and synchronized through GitHub.

## Workflow

1. Open the published Codex cloud environment connected to this repository on mobile.
2. Complete a coding task, review the changes, and push a branch or create a pull request.
3. Merge the pull request into `main` when ready, then pull `main` on the computer.

A cloud workspace and a local Git checkout are separate copies. Changes become available to the other copy after they are committed and pushed to GitHub.
